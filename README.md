# Система мониторинга состояния растений

Рабочая десктопная версия лабораторной работы №2 по ОМИС. 

## Запуск в Windows

Требуется Python 3.10 или новее.

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Для демонстрационного входа пароль `demo123`. Email можно оставить пустым - тогда используется демонстрационная учётная запись выбранной роли. Также можно ввести email вручную.

| Роль                                      | Email для демо           |
|-------------------------------------------|--------------------------|
| Агроном                                   | `agronomist@example.com` |
| Агроскаут                                 | `scout@example.com`      |
| Инженер-механизатор                       | `engineer@example.com`   | 
| Аналитик                                  | `analyst@example.com`    | 
| Государственное / экологическое ведомство | `agency@example.com`     | 


## Хранение данных

SQLite создаётся автоматически в `database/plant_monitoring.db`. При первом запуске добавляются демонстрационные поля, датчики, показания с историей, проблемные зоны, задания и учётные записи. Существующая база обновляется миграцией без удаления данных.

## Сохранение структуры проекта

Основные классы и подсистемы сохранены: сущности, репозитории, контроллеры, интерфейсы представления, приложение. Для работающих пользовательских сценариев добавлены недостающие методы репозиториев и контроллеров, а также технические таблицы хранения событий оборудования, ремонтов, техники и связей сенсоров.

## Docker

Docker по-прежнему не используется. Приложение работает локально на SQLite, чтобы не требовать Docker Desktop и отдельный сервер БД на личном ноутбуке.
